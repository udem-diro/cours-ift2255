## Trois routes, selon le besoin

| Besoin | Route |
|---|---|
| Un seul cours : puis-je le suivre ? | `POST /courses/{id}/eligibility` |
| Tous les cours d'un programme que je peux suivre | `POST /programs/{id}/eligible-courses` |
| Un ensemble de cours pour une session, avec les conflits d'horaire | `POST /courseplan/check` |

Ce guide présente la troisième, la plus complète. Les deux autres renvoient la même évaluation
(voir [Évaluation des exigences](/guide-api/donnees/evaluation/)).

## La requête

| Champ | Rôle |
|---|---|
| `semester` | La session **(obligatoire)** |
| `courses` | Les cours prévus ; déduits de `sections` si la liste est vide |
| `sections` | Les sections et options choisies, pour les conflits (identifiants de [Horaires](/guide-api/donnees/horaires/#identifiants-de-section)) |
| `checks` | `eligibility`, `conflicts`, ou les deux (par défaut) |
| `completed_courses`, `program_id`, `gpa`, `total_credits` | La situation de l'étudiant |

## La réponse

```json
{
  "semester": "A26",
  "credits": 7.0,
  "courses": [
    { "id": "IFT2255", "name": "Génie logiciel", "credits": 3.0,
      "offered": { "term": true, "schedule": true },
      "eligibility": { "status": "yes", "missing_courses": [], "unmet": [], "to_verify": [],
                       "via_equivalent": [], "concomitants": null } }
  ],
  "selected": ["A26IFT2255A", "A26MAT1400A"],
  "conflicts": [
    { "kind": "meeting", "a": "A26IFT2255A", "b": "A26MAT1400A", "day": "Ma",
      "a_time": "13:30-15:29", "b_time": "14:30-16:29", "dates": [["2026-09-01", "2026-12-09"]] }
  ],
  "warnings": [],
  "unselected": [],
  "missing_choices": [],
  "unscheduled": [],
  "issues": []
}
```

*Exemple illustratif.*

| Champ | Contenu |
|---|---|
| `courses[].eligibility` | Le résultat de l'évaluation ; `concomitants` indique les cours à suivre en même temps qui ne sont ni réussis ni prévus |
| `courses[].offered` | `term` : offert habituellement à cette saison ; `schedule` : un horaire existe pour la session (`null` si la base n'a encore aucun horaire pour cette session) |
| `selected` | Les sections et options réellement vérifiées, y compris celles retenues automatiquement |
| `conflicts` | Paires en conflit : rencontres (`meeting`) ou examens (`exam`), avec les plages de dates communes |
| `warnings` | Deux examens le même jour, sans chevauchement |
| `unselected` | Cours qui ont plusieurs sections : il faut en choisir une |
| `missing_choices` | Sections dont un choix (TP, atelier) n'a pas d'option sélectionnée |
| `unscheduled` | Activités sans horaire des sections retenues |
| `issues` | Problèmes du plan : cours déjà réussi, doublon par équivalence, exclusion, préalable prévu à la même session, identifiant inconnu, plusieurs sections du même cours |

## Bon à savoir

- **Un cours qui n'a qu'une section** la voit retenue automatiquement : inutile de l'envoyer.
- **Choisir une option** (`A26MMD1108A1`) implique sa section.
- **Les concomitants** sont satisfaits par les cours prévus à la même session.
- **Un cours de demi-session** n'est en conflit que pendant les semaines communes (voir `dates`).
- **Pour une session lointaine** sans horaire en base, seule l'éligibilité est vérifiée.
